# ToolVerse

A client-side collection of free browser utilities.

## GitHub Pages

Upload these files to a GitHub repository:

- `index.html`
- `manifest.json`
- `sw.js`

Then enable **Settings → Pages → Deploy from a branch**.

The project is static and does not require Hatchable, a database, or a backend.

## Privacy

The included image tools process selected images in the browser. No upload endpoint is included.

## Important

This is the currently tested ToolVerse core, not a claim that every tool in the original master prompt has been implemented.
